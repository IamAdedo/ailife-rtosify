# RTOSify Companion — Watch App

The **smartwatch** side of the RTOSify Android watch-tethering system.

Install this on any Android smartwatch. It pairs with the **RTOSify Phone App** to deliver the full feature set of a premium smartwatch — Apple Watch Ultra 3, Pixel Watch 3, Samsung Galaxy Watch 7 Ultra, and Huawei Band 9 — on any Android wearable.

## Architecture

```
BluetoothService (foreground)
    └── TransportManager
            ├── BluetoothTransport    (Classic RFCOMM — primary)
            ├── BleTransport          (BLE GATT)
            ├── WifiIntranetTransport (TCP over LAN)
            └── WebRtcTransport       (Internet)
```

Feature modules run as lightweight managers inside `BluetoothService`, sharing a single foreground lifecycle to preserve battery.

## Features

### 📡 Connectivity
- Multi-transport: BT Classic → BLE → WiFi → Internet auto-switching
- BLE GATT server for proximity detection
- Bluetooth PAN for sharing phone internet to watch
- Encrypted transport
- mDNS discovery on local network

### 🔔 Notifications
- Receives and displays all phone notifications
- Inline reply (type on watch keyboard or use AI quick replies)
- Dismiss synced back to phone
- **Dynamic Island** floating overlay style
- Notification log with full history
- Per-app notification filtering
- **AI Quick Replies**: one-tap replies generated by Claude AI on the phone

### 🏥 Health & Medical (on-device sensors)

**Continuous monitoring:**
- Heart rate (optical HR sensor)
- SpO2 / blood oxygen
- Wrist skin temperature
- Step count and cadence
- HRV (SDNN) for stress monitoring

**On-demand measurements:**
- **ECG** — 30-second single-lead reading with AFib classification
- **Respiratory rate** — accelerometer Z-axis zero-crossing method
- **Body composition** — body fat %, muscle mass, BMI, BMR (Deurenberg formula)
- **Blood pressure trend** — PTT-based proxy with personal calibration

**Sleep tracking (automatic):**
- Sleep onset / wake detection via accelerometer + HR drop
- Stage classification: Deep / REM / Light / Awake
- Sleep score 0–100
- **Sleep apnea screening** — SpO2 dips + stillness pattern
- **Snoring detection** — burst microphone sampling during sleep
- **Smart Alarm** — wakes during lightest sleep stage within configurable window
- **White noise / soundscapes** — on-device audio synthesis: WHITE_NOISE, PINK_NOISE, RAIN, OCEAN, BROWN_NOISE with smooth fade-out
- **Breathing quality score** — respiratory rate during sleep

**Computed metrics (sent to phone):**
- **Daily Readiness Score** (Pixel Watch-style): 3-pillar composite using sleep, resting HR, HRV baselines
- **Energy Score** (Samsung-style): 5-pillar: sleep + activity + HRV + SpO2 + skin temperature
- **Cardio Load + Target Load**: ATL/CTL acute:chronic model, overtraining risk
- **VO₂Max estimate** (Uth-Sørensen + Daniels running pace methods)
- **Running Ability Index** with 5K/10K pace projections
- **HR Recovery** classification: Excellent/Good/Average/Poor
- **Recovery time** recommendation (TRIMP-based hours)
- **Premature beat detection** (RR-interval analysis): OCCASIONAL / FREQUENT / BIGEMINY

### 🏃 Fitness & Workouts

**WorkoutActivity** — multi-sport tracker:
- RUNNING, CYCLING, SWIMMING, HIKING, HIIT, ROWING
- Live: HR + zone, pace, distance (GPS from phone), cadence, calories
- Zone time breakdown, post-workout evaluation

**Auto-detection:**
- Watch automatically detects RUNNING / WALKING / CYCLING / ROWING from accelerometer patterns (2-window confirmation)

**Triathlon mode (TriathlonActivity):**
- SWIM → T1 → BIKE → T2 → RUN sequential tracking
- Auto-transition via accelerometer signature
- Per-segment: duration, distance, avg HR
- Sport colour-coded UI with segment dot indicators

**Running Coach (real-time):**
- Cadence analysis every 30 seconds
- Vertical oscillation estimation
- Haptic cues: CADENCE_LOW / CADENCE_HIGH / OVERSTRIDING / GOOD_FORM

**Advanced fitness:**
- Custom interval workouts pushed from phone
- Pace target cues with haptic feedback (TOO_FAST / ON_PACE / TOO_SLOW)
- Personal record celebration haptic + notification

**Activity Rings (ActivityRingsManager):**
- Move (calories), Exercise (HR-zone minutes), Stand (hourly)
- **Sedentary reminder**: vibrates + shows notification after 50 min of inactivity
- **Stand reminder**: vibrates + notifies at :50 each hour if not stood
- Daily persistence with midnight reset
- Syncs ring progress to phone every 5 minutes

### 🛡️ Safety

| Feature | Detail |
|---|---|
| **Emergency SOS** (SosActivity) | Long-press → 20s countdown → phone dials 112 + SMS contacts |
| **Fall detection** (FallDetectionService) | Freefall + impact signature; 30s confirm window; auto-escalates |
| **Crash detection** | Higher-threshold multi-axis impact pattern |
| **Loss of Pulse** (LossOfPulseDetector) | 30s absent pulse + wear detection → 15s confirm → phone dials 112 |
| **Emergency Siren** (EmergencySirenManager) | 880/1320 Hz alternating tone up to 120s, sync vibration |
| **Health alerts** | Irregular rhythm, low SpO2, high/low HR → phone notification |
| **Noise monitoring** (NoiseLevelMonitor) | 85 dB burst-mic alert after 30s sustained exposure |
| **Handwash detection** (HandwashDetector) | Wrist rubbing + water sound → 20s haptic countdown timer |

### 📍 Anti-Lost (bidirectional)

**Watch alerts you when your phone is left behind:**
- Monitors Bluetooth RSSI of the paired phone continuously
- 3 consecutive weak readings (below configurable threshold, default −75 dBm) → alert
- Repeating haptic pattern every 5 seconds + persistent notification
- Auto-clears when phone comes back in range
- Also alerts immediately on full BT disconnect

**Phone alerts the user** when the watch moves out of range (phone left behind — see phone app).

## Supported Smartwatches

Any Android wearable running Android 8.0+ with:
- Bluetooth (Classic + BLE)
- Heart rate sensor
- Accelerometer

Optional hardware unlocks additional features:
- **Optical SpO2 sensor** → blood oxygen monitoring
- **Barometer** → altitude, elevation, storm warning
- **Magnetometer** → compass
- **Microphone** → snoring detection, noise monitoring, handwash detection, walkie-talkie
- **Speaker** → emergency siren, white noise, walkie-talkie playback
- **NFC** → Google Pay / tap-to-pay
- **Temperature sensor** → skin temperature tracking, energy score

## Setup

1. Install **RTOSify Phone App** on your phone first
2. Install this APK on your Android smartwatch
3. Open the companion app → select **Smartwatch mode**
4. Scan the QR code shown in the phone app
5. Grant permissions (Bluetooth, Notifications, Body Sensors, Microphone)

## Build

```bash
cd companion
./gradlew assembleDebug     # debug APK
./gradlew assembleRelease   # release APK (unsigned)
./gradlew test              # unit tests
```

Requires **JDK 17**. AGP 8.13.1, Gradle 8.13.
